# Merged Downloader - build without Android Studio
1. Create a free GitHub account, make a new repository.
2. Upload ALL files/folders from this project (keep the folder structure, including the hidden .github folder).
3. Open the repo > Actions tab > "Build APK" > wait ~5 min.
4. Open the finished run > Artifacts > download MergedDownloader-apk, unzip, install app-debug.apk on your phone.
